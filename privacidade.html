Política de Privacidade

Última atualização: 12 de outubro de 2026.

O que é

O Coletor Enel é uma ferramenta de uso pessoal. Só é usada pelo próprio dono, na própria conta.

Quais dados acessa

Com a permissão de somente leitura do Gmail (gmail.readonly), a ferramenta procura os e-mails de fatura enviados pela Enel e extrai apenas o valor, o vencimento e o mês de referência da conta de energia.

Como os dados são usados

Esses dados são enviados apenas para o app de controle financeiro pessoal do próprio dono, que roda no computador dele. Nenhum outro e-mail é guardado.

Compartilhamento

Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Uso dos dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
